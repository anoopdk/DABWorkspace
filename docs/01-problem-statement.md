# Problem statement

## Client context

- **Delivery organisation:** Zynx Technologies Ltd
- **Domain client:** Digital Platform Client
- **Engagement type:** Enablement / Foundation Delivery

## Business problem

The Digital Platform Client needed a clean Databricks Asset Bundle (DAB) workspace baseline so engineering teams could deploy notebooks and jobs consistently across dev and prod targets without manual workspace drift.

## Success criteria (engagement)

- Clear architecture and ownership model
- Inspectable artefacts in Git (docs, diagrams, code/notebooks)
- Domain-safe documentation suitable for public portfolio audit
- Handover path for client engineering teams
